# RushTrack Studio downloads

Official Windows desktop downloads for RushTrack local subtitles.

Download the installer from [Releases](https://github.com/cinergiapost/rushtrack-studio-releases/releases). An active RushTrack Studio Team or Enterprise account is required to activate the application. Open it from your project’s Delivery → Subtitles page.

Video, audio, speech recognition and translation remain on your computer. Project subtitles, corrections and metadata are saved to RushTrack with your signed-in session.

## Windows preview

The first Windows version is an unsigned preview. Windows may display an unknown-publisher warning or prevent installation according to your organization’s policy; do not disable Windows protections. Installation requires administrator access to configure the local processing network rules. This repository hosts installers only and never contains customer media or project records.

Bundled third-party notices and public component provenance are included in the installation. Installer checksums and package verification details appear in each release.
